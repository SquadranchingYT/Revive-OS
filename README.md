# Revive OS

> Next-Generation Unblocked Gaming Operating System with Arcade Classics, Stealth Cloak, and Built-In Applications.

![Revive OS Banner](./src/assets/images/revive_os_wallpaper_1792544995104.jpg)

## Features

- **26+ Playable Games**: Slope 3D, Cosmic Pinball, Galactic Gem Blast, Cyber Racer, Galactic Invaders, Tetris, Snake, Asteroids, Breakout, Pac Maze, Tower Defense, Cyber Crosser, Lunar Lander, Cyber Archery, and more.
- **Multitasking Window Manager**: Draggable, resizable, minimizable, and maximizable windows with taskbar and start menu.
- **Emergency Stealth Cloak**: Quick panic key (configurable to `Escape`, `~`, `F2`, or `Tab`) instantly hides the OS behind realistic Google Classroom, Google Docs, Khan Academy, or Desmos screens with matching browser tab titles and favicons.
- **System Applications**: Revive Game Hub, Beatpad 808, File Explorer, Focus Timer (Pomodoro), Web Surfer, Paint Studio, Scientific Calculator, Cyber Terminal, Task Manager, Sound Lab, and System Benchmark.
- **Cyberpunk Audio Engine**: Dependency-free browser Web Audio synthesizer for arcade sound effects and music.

## GitHub Pages Deployment

This repository includes an automated GitHub Actions workflow (`.github/workflows/deploy.yml`) to deploy Revive OS to GitHub Pages:

1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push to `main` (or run the workflow manually under **Actions** > **Deploy Revive OS to GitHub Pages**).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.
